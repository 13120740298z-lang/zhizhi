## 这是什么

命题问的是「**让 AI 决定每一度电怎么用**」。
我们的回答是：**先让 AI 决定「它能决定多少」**。

家庭储能的推广瓶颈不是算法不够聪明，而是**用户不敢把控制权交出去**。
而用户不敢交权是理性的 —— 备电场景后果不可逆、损失由用户承担、算法不承担。

所有系统都在装作很确定：给你一个「能撑 4 小时」、一个「省 47 元」，从不告诉你这个数字有多不可靠。

**知止**给家庭能源 AI 装上**可验证的刹车与凭据**：

| 角色 | 尺度 | 它要做的决定 |
|---|---|---|
| **套利者** | 日 | 凌晨该充多少？高峰该放多少？ |
| **会攒钱的电池** | 跨天 | 连阴三天时，今天该放掉还是留给更贵的那天？ |
| **守护者** | 秒 | 台风预警时，充满够冰箱和路由器撑多久？**最差能撑多久？** |

**一条底线**：它从不说自己没把握的数字。

## 三个核心机制

### 1. 置信度驱动的自主降级

系统持续自评**三类置信度**（预测 / 数据 / 决策），并**用它作为唯一自动判据**决定当前授权等级：

| 等级 | 承诺 | 明确不做 |
|---|---|---|
| **L0 只读** | 展示带区间的结论；**执行保护性动作** | 不执行优化性充放电 |
| **L1 建议** | 给建议 + 代价 + 置信度 | 不自动执行优化性动作 |
| **L2 例外审批** | 常规自动；触碰边界先问 | 不越界执行 |
| **L3 全托管** | 全自动；降级必通知、原因必可查 | 不静默降级 |

实测因果链（幕一，注入价格波动）：

```
价格不确定性 0.142 → 1.0  →  整体置信度 65% → 43%  →  授权等级 L3 → L1
```

### 2. 不确定性是一等公民

所有结论都以 **P10/P50/P90** 输出：不是「能撑 4 小时」，而是「**能撑 3.7 小时（P50），最差 2.3 小时（P10）**」。

区间宽度同时是**输出、输入和判据**：预测偏差 → 区间变宽 → 置信度下降 → 自动降级。
跨天规划里**悲观程度由不确定性驱动**（α = f(uncertainty)），而不是无条件保守 —— 该保守时才保守。

### 3. 不可满足诊断

目标做不到时，给出**最小冲突集**与**可执行的替代方案**：

> **用户**：「明天全天不用电网的电。」
> **系统**：做不到。冲突集 {全天不使用电网电力}。
> 全天光伏只发 11.2 kWh，抵不过总负荷 14.9 kWh，差的 3.8 kWh 电池补不上（**电池只能搬运，不能发电**）。
> 三条路径：A. 电池 5.0→17.6 kWh + 光伏 2.4→10.3 kWp（**已验证可达**）｜B. 挪负荷 → 电网取电 5.14→3.39 kWh｜C. 接受 5.14 kWh（电费约 0.88 元）

## 本地运行完整系统

```bash
cd zhizhi
uv venv --python 3.12 .venv && uv pip install --python .venv -e ".[dev]"

.venv/Scripts/python -m pytest -q                    # 79 passed
.venv/Scripts/python -m zhizhi.cli demo --act all    # 三幕演示
.venv/Scripts/python -m zhizhi.cli report all        # 校准度 + 基线对照报告
.venv/Scripts/python -m zhizhi.cli audit verify      # 审计哈希链校验
.venv/Scripts/python -m zhizhi.cli serve             # http://127.0.0.1:8000
```

## 验证与诚实边界

**已实测**：79 项自动化测试全绿（总覆盖率 84%，置信度评估器与护栏层 95%）· 三幕演示 3/3 · 审计哈希链校验通过 · 校准度三源覆盖率收敛至 0.80。

**主动公布的「治理成本」**（S2 知止 − S1 纯优化器）：

| 场景 | 治理成本 | 买到了什么 | 同时付出的代价 |
|---|---|---|---|
| 幕一 · 正常天气 | +1.33 元（12.8%） | 悲观世界电费反而低 0.37 元 | — |
| 幕二 · 连阴三天 | +0.97 元 | 峰段取电减少 0.87 kWh | — |
| 幕三 · 台风预警 | +4.86 元 | **备电违约 349 段 → 3 段** | 峰段多买 5.78 kWh |

> **一个敢于公布自己保费的方案，比一个声称「又省钱又安全」的方案可信得多。**

**我们主动不声称**：不是我们提出「LLM 不应直接控制能源设备」；不是我们提出「家庭能源自主性分级」（SEPA/Powerley 2019、Sigenergy EIL 2026-05 已提出）；不是我们做 What-if 沙盒（Predbat 已完整落地）。

**局限**：校准与对照基于**物理自洽的仿真序列**（样本外），证明的是机制有效，不等于真实市场精度。新颖性核查**只覆盖英文开源与学术通道**（IEEE Xplore / Scopus 未系统检索，CNKI / 万方 / 专利库完全未覆盖），因此不能断言「中文先例与专利不存在」。
